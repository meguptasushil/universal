Connect to your relay

A relay is the server that gives your apps a public address. Whoever runs it gives you a connection code (it starts with uni1.). Paste it here.

I don't have a relay yet

Rent any small cloud server (Linux, about $5 a month, from any provider) and run this one line on it:

curl -fsSL https://raw.githubusercontent.com/meguptasushil/universal/main/deploy/install.sh | sudo sh -s -- relay

That's it: no domain or DNS setup needed. When it finishes it prints a connection code. Paste that code above. Want your own domain (like myapps.com)? See the guide in the project's docs/GETTING-STARTED.md.
